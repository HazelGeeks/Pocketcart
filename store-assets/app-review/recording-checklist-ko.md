# PocketCart 심사용 직접 촬영 순서

목표: iPhone 17 Pro / iOS 27.0 / PocketCart 1.0.0 (18)에서 약 4~6분. 시간은 촬영 편의를 위한 권장치입니다.

## 촬영 전

- TestFlight에서 빌드 18인지 확인합니다. 촬영한 빌드와 App Store 심사에 연결하는 빌드를 맞춥니다. 현재 반려된 제출에는 빌드 17이 연결되어 있습니다.
- 별도의 삭제 가능한 테스트 계정을 사용합니다. 운영자 계정과 심사용 `test@pocketcart.app` 계정은 삭제하지 않습니다.
- 알림에 개인 정보가 나타나지 않게 준비하고 영수증에는 아래의 가상 데이터를 사용합니다.
- 영상은 iPhone 홈 화면에서 PocketCart 아이콘을 눌러 실행하는 장면으로 시작합니다.

## 장면 순서

1. **앱 실행 → 회원가입 → 로그인** (약 1분)
   새 테스트 계정 생성 → 필요한 이메일 인증 → 로그아웃 → 같은 계정 로그인. 비밀번호는 숨겨진 상태로 둡니다.
2. **상품 탐색 → 장바구니 → 할인 알림** (약 1분)
   Home에서 상품 선택 → 매장과 가격 확인 → Add to cart → Cart에서 수량 변경과 소계 확인 → Purchased 표시. 상품 상세의 Notify me when on sale을 켜고 Manage에서 저장된 상품을 보여줍니다.
3. **My Freezer** (약 30초)
   Add food로 가상의 식품을 추가하고 보관 위치·수량·날짜를 입력합니다. 다른 탭으로 이동했다 돌아와 저장된 항목을 보여줍니다.
4. **추가 기능** (약 1분)
   Account > Features > Map에서 매장 검색. Receipts에서 가상 영수증 수동 입력·저장. Scan 또는 영수증 사진 읽기를 시연할 때는 OpenAI로 사진 전송 전 동의 화면과 결과 검토 과정을 포함합니다. 사진 기능을 사용하면 개인 영수증 대신 가상 자료를 촬영합니다.
5. **공유·무료 기능 안내** (약 30초)
   Account > Family의 초대 전용 공유 및 실제 제공되는 회원 제거/초대 취소/나가기 기능을 보여줍니다. 실제 연락처에 초대하지 않습니다. Pocketcart Plus 화면에서 구독 없이 기능을 사용할 수 있다는 안내를 보여줍니다. 별도의 신고·차단 UI는 구현되어 있지 않으므로 존재한다고 설명하지 않습니다.
6. **계정 삭제 완료** (약 30초)
   처음 만든 테스트 계정에서 Account > Account actions > Delete Account → 확인 → 로그아웃/삭제 완료 화면까지 촬영합니다. 가능하면 동일 계정의 재로그인이 거절되는 것도 보여줍니다.

## 제출 전 문안 완성

- response-draft.txt와 notes-draft.txt는 동일한 4,000자 이내 영문 초안입니다.
- 대괄호 입력란 3개(영상, 데이터 출처, 콘텐츠 권한)를 사실에 맞게 채웁니다. 추가 문구를 넣으면 Notes의 4,000자 제한을 다시 확인합니다.
- 영상 전체를 재생해 앱 실행·가입·로그인·주요 기능·삭제 장면과 글자 가독성을 확인합니다. 링크 방식이면 심사자가 접근 가능한지 확인합니다.
- 완성 문안을 App Review 답변과 App Review Information의 Notes에 각각 넣습니다. 로그인 자격 증명은 전용 Sign-in information 필드에 유지합니다.
- 빌드 18의 검증 결과를 빌드 17의 결과로 설명하지 않습니다.

## 현재까지의 직접 확인 범위

빌드 18 설치, 실제 기기 실행, 이메일 로그인, 상품 탐색, 장바구니 추가/수량/소계/구매 완료, 할인 알림 저장과 앱 내 표시, My Freezer 항목 저장·재조회, 지도 및 Receipts 화면 접근을 확인했습니다. 가입·계정 삭제, AI 사진 분석, 가족 초대/제거, 실제 푸시 수신까지 모두 검증 완료된 것은 아닙니다.

사용자 요청으로 자동 녹화/전체 QA 진행을 중단하고 직접 촬영 가이드와 문안 준비로 범위를 변경했습니다. 자동 녹화 원본은 심사 제출용으로 확정하거나 업로드하지 않았습니다.
