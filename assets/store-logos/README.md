# Store logo assets

These compact official icons were added on 2026-10-08 for map markers and store
cards. They are bundled locally so maps do not require third-party image requests.

| Asset | Official source |
| --- | --- |
| `safeway.png` | [Safeway Canada favicon](https://www.safeway.ca/favicon.ico), largest 48×48 ICO frame converted to RGBA PNG |
| `real-canadian-superstore.png` | [Real Canadian Superstore icon](https://assets.shop.loblaws.ca/ContentMedia/rcss/logos/64x64icon.ico), supplied as a 64×64 PNG |

Both sources are linked by the respective official retailer homepages. Icon
artwork and colors are preserved; the Superstore badge background is `#005AA8`.
